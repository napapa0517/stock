# 주식 데일리 브리핑

시황 브리핑, 상한가 기록, 자산현황, 재테크농부·다른 AI 자료를 한곳에서 보고 관리하는 1인용 웹앱이에요.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 동작해요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인(라이트·다크 자동) |
| `app.js` | 동작과 저장(브라우저 localStorage) |
| `apps-script/Code.gs` | Google Sheets를 읽어 오는 연결 코드(시트의 Apps Script에 붙여 넣음) |
| `주식 데일리 브리핑 도구 PRD.md` | 기획 문서 |

## 화면

1. **오늘의 브리핑**: 날짜와 종류(오전·오후·휴장일·종합)를 고르면 브리핑을 보여줘요.
   - 내 종목은 초록색, "미확인"은 노란색으로 표시돼요.
   - "카페용 복사"를 누르면 브리핑을 카페에 붙여 넣을 수 있게 복사해요. 종합 브리핑은 자산 금액이 들어 있어 복사 전에 한 번 더 확인해요.
   - 맨 위 **브리핑 달력**에서 날짜를 고르면 그날 브리핑과 **요약 이미지**가 보여요. 색 점은 브리핑 종류(파랑 오전·빨강 오후·회색 휴장일·초록 종합), 🖼 숫자는 이미지 수예요.
   - **이미지 올리기**로 그날 요약 카드 이미지를 여러 장 올릴 수 있어요(시트 연결 필요). 이미지는 Drive `주식브리핑/브리핑이미지` 폴더에 비공개로 저장되고, 목록은 시트 `이미지` 탭에 남아요. 큰 이미지는 가로 1600px로 줄여 저장해요.
   - 오전·휴장일 브리핑에는 **주요 뉴스 TOP 20** 카드가 위에 붙어요. 기사마다 사실·수치·국내 영향 3줄과 출처(매체·원문 링크)가 보여요. 시트 `뉴스` 탭에 자료가 있으면 그걸 쓰고, 없으면 브리핑 본문에서 뽑아요.
2. **기록·검색**: 상한가 기록을 종목명·섹터·사유로 검색하고, 지난 브리핑을 찾아요.
   - **상한가 달력**: 날짜마다 상한가가 몇 개였는지 보여요. 날짜를 누르면 그날 종목만 표에 나와요.
   - **누적 기록**: `종목분석_누적관리`의 `주간월간누적_요약`과 `달력_통합` 탭을 그대로 보여 줘요. 위쪽 버튼으로 두 화면을 바꿔 봐요. S·A·B 등급은 색으로 표시돼요.
   - 상한가는 자동 실행이 쌓는 기록(`주식브리핑_DB` 상한가 탭)과 직접 쌓는 누적 기록(`종목분석_누적관리` 종목_마스터의 상한가 O 행)을 합쳐 보여 줘요. 같은 날짜·종목은 한 번만 보여요.
3. **자산현황**: 보유 종목, 환율, 예수금을 입력하면 총자산, 손익, 비중을 계산해요. 주간 기록도 쌓을 수 있어요.
4. **재농·AI 자료**: 재테크농부 스크랩과 ChatGPT 등 다른 AI의 분석을 모아 둬요. "요청문 복사"를 누르면 Claude에 붙여 넣을 종합 브리핑 요청문이 만들어져요.
5. **설정·백업**: 관심 종목을 적고, 자료를 백업 파일로 내려받거나 다시 불러와요.

## 자료 넣기

- Google Sheets `주식브리핑_DB`의 탭을 복사해 각 화면의 "시트에서 붙여넣기"에 붙여 넣으면 한 번에 들어가요.
  - 브리핑: A~F열
  - 상한가: A~I열
  - 자산_보유: A~H열
- 하나씩 넣을 때는 "새 브리핑", "상한가 추가", "종목 추가"를 쓰세요.

## Google Sheets 연결 (Apps Script)

연결하면 시트 `주식브리핑_DB`의 브리핑, 상한가, 자산현황, 실행기록을 웹앱이 자동으로 불러와요.
자동 실행이 쓴 브리핑과 시트의 현재가·환율이 그대로 보여요.
웹앱이 시트에 쓰는 곳은 **`재농AI자료` 탭 하나**예요. 재농·AI 자료를 저장·삭제하면 이 탭에 반영되고, Claude가 종합 브리핑을 만들 때 이 탭을 읽어요. 다른 탭은 읽기만 해요.

### 1. Apps Script 넣기 (한 번만)

1. Google Sheets에서 `주식브리핑_DB`를 열어요.
2. 메뉴 **확장 프로그램 → Apps Script**를 눌러요.
3. 왼쪽 `Code.gs`의 내용을 모두 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 붙여 넣은 뒤 저장(Ctrl+S)해요.

### 2. 비밀 키 만들기

1. 위쪽 함수 선택 칸에서 `setupToken`을 고르고 **실행**을 눌러요.
2. 처음 실행하면 권한 확인 창이 떠요. 본인 계정을 고르고 허용해요.
   - "확인되지 않은 앱" 화면이 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 본인이 만든 스크립트라서 나오는 화면이에요.
3. 아래 **실행 로그**에 나온 `비밀 키: ...` 값을 복사해 둬요.

### 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 톱니바퀴에서 유형 **웹 앱**을 골라요.
3. 설정을 이렇게 해요.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누르고 나온 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사해요.

### 4. 웹앱에 넣기

1. 웹앱의 **설정·백업** 탭에서 연결 주소와 비밀 키를 넣고 **연결하고 불러오기**를 눌러요.
2. 위쪽에 "시트 연결됨"이 보이면 성공이에요. 이후에는 웹앱을 열 때마다 자동으로 불러오고, **시트에서 새로고침** 버튼으로 다시 불러올 수 있어요.

### 연결 후 달라지는 점

- 브리핑, 상한가, 자산현황은 시트 내용이 그대로 보여요. 고칠 때는 시트를 고쳐요(웹앱의 추가·수정 버튼은 숨겨져요).
- 재농·AI 자료는 이 브라우저와 시트 `재농AI자료` 탭에 함께 저장돼요. 연결 전에 넣은 자료는 처음 불러올 때 시트로 올라가요.
- 종합 브리핑은 Claude 채팅에서 "종합 브리핑 만들어줘"라고 하면 만들어져 시트에 저장돼요. 웹앱에서 "시트에서 새로고침"을 누르면 "종합"에 보여요.
- 관심 종목은 이 브라우저에만 저장돼요.
- **기록·검색** 탭에 자동 실행 기록(최근 20건)이 나와요.

### 보안 메모

- 웹 앱 주소는 누구나 열 수 있지만, 자료는 **비밀 키가 맞을 때만** 내보내요. 주소만 열면 안내 문구만 보여요.
- 비밀 키는 코드(GitHub)에 적지 않아요. 각 브라우저의 설정 탭에 한 번씩 넣고, 백업 파일에도 들어가지 않아요.
- 키가 새었다고 생각되면 Apps Script에서 `setupToken`을 다시 실행해요. 새 키가 만들어지고 예전 키는 바로 막혀요. 새 키를 웹앱에 다시 넣으면 돼요.
- `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영돼요.

## 저장 위치와 주의

- 시트를 연결하지 않으면 자료는 **지금 쓰는 브라우저에만** 저장돼요. 별도 서버나 데이터베이스는 쓰지 않아요.
- 다른 PC나 휴대폰에서는 자료가 보이지 않아요. 백업 파일로 옮기세요.
- 브라우저 기록(사이트 데이터)을 지우면 자료도 지워져요. 가끔 백업하세요.
- 백업 파일(`주식브리핑_백업_*.json`)에는 자산 금액이 들어 있어요. GitHub에 올리지 마세요. `.gitignore`에 넣어 두었어요.

2. Vercel에서 그 저장소를 가져와(Import) 그대로 배포해요.

   - Build Command: 비워 둠
   - Output Directory: 비워 둠
3. 배포 주소는 누구나 열 수 있어요. 하지만 자료는 각자의 브라우저에만 있어서 다른 사람에게는 빈 화면만 보여요.
